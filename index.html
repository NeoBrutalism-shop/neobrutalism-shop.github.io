TACTILE MOTION GRAMMAR

The shadow is not decoration.
It is depth.

A NeoBrutal control does not float upward when you approach it. Hover makes contact. Press consumes the remaining depth. Release restores the surface.

01

Fluid foundations

Type, space and control sizing use bounded clamp() scales instead of breakpoint piles.

02

Semantic physics

Motion explains affordance, state and cause. Interactive surfaces compress. Dragging is allowed to lift because the object is actually picked up.

03

Accessible by contract

Keyboard behavior, focus, reduced motion, forced colors, contrast and responsive resilience are release gates.

04

Agent-readable

Machine manifests, stable semantics and LLM guidance make the system usable by code-generating agents without visual guesswork.
